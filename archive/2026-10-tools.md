## Tool evaluation checklist

Derived from the standing rule above — not from observation about the owner.

- [ ] Is it free forever, or free until a date / quota runs out?
- [ ] What exactly is the limit? Write the number down.
- [ ] Does it require a credit card to start?
- [ ] Does it require an account, or can it run locally with no signup?
- [ ] Can it be exported from? (Avoid anything that traps the data.)
- [ ] Does it need self-hosting? If yes, say so up front — that's unfamiliar territory, so it
      needs an explicit warning, not a step buried in the middle of a guide.
- [ ] At the owner's level (edits files, runs simple commands — not a server admin), is this
      actually usable?
